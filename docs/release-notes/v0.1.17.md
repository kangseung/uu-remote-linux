# v0.1.17

## 修复

- **官方控制端提示「被控端版本较低，建议您更新被控端」**：被控端向网易云端上报的客户端版本一直
  停在 `4.42.0.2770`，官方 Windows / Mac / 手机控制端已经演进到 4.45，因此判定被控端落后，
  部分新特性（如缩放）被禁用，连接后不久就弹窗。现在上报版本提升到官方 Windows 主线基线
  `4.45.0.4318`：
  - `x-param-vn` → `4.45.0.4318`，`x-param-vc` → `4318`；
  - `User-Agent` → `UURemote/4.45.0 (Windows NT 10.0; Win64; x64)`；
  - 版本号由 `src/auth.rs` 的 `DEFAULT_CLIENT_VERSION` 单点推导：`x-param-vc` 取最后一段，
    `User-Agent` 取前三段，不再需要三处同步修改。
- 新增环境变量 **`UU_CLIENT_VERSION`** 覆盖上报版本，官方再次升版时不用重新编译：
  `UU_CLIENT_VERSION=4.50.0.5000 uuremote-server`。

## 注意

控制端会按被控端上报的版本决定发送哪些新协议消息。若某个新特性在本版本上表现异常，可用
`UU_CLIENT_VERSION=4.42.0.2770` 退回旧的版本声明，并在日志里查看对应的
`CONTROL message: fields=[..]` 行。

## 验证

- `cargo test --locked --features wayland,portal`：新增 `auth::reported_version_tests`，
  默认版本、版本号与 User-Agent 推导均有断言。
