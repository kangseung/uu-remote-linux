# v0.1.16

## 修复

- **杀掉手机 App 后，电脑上的"屏幕共享中"指示（KDE 红点）和自动勿扰不消失**：portal 抓屏会话在
  第一次桌面连接后一直持有，进程不退出就不关闭，KDE 因此认为桌面始终在被共享。现在：
  - 收到云端的 `released`/`left`（对端离开）后，若不再有任何桌面会话，立即关闭 portal 抓屏会话
    （`release_idle_desktop_capture`，`src/main.rs`）；
  - 主事件循环增加 5 秒清理节拍：App 被直接杀掉、断网等云端不发通知的情况，对等连接进入
    Closed/Failed 后会被清扫，同样触发会话关闭；
  - 下次手机连接时通过已持久化的 restore token 静默重开抓屏会话，不弹授权框（与锁屏→解锁后的
    会话重建同一条路径，该路径已验证无弹窗）。
  文件传输、终端等其他会话不受影响；X11 / Hyprland 原生后端不持有 portal 会话，行为不变。

## 验证

- `cargo test --locked`：122 passed；`cargo check --features wayland,portal` 通过。
