### 修复 / Fixed
- **ffmpeg 4.4 下桌面视频完全起不来**：编码器命令行硬编码了 `-fps_mode vfr`（ffmpeg 5.1 才引入，4.4 直接报
  `Unrecognized option 'fps_mode'` 退出），导致 Ubuntu 22.04 / Mint 21 / Debian 12 上连接后永远黑屏/转圈。
  现在启动编码器前会探测一次 ffmpeg 支持的参数形式：新版本用 `-fps_mode vfr`，老版本自动换成等效的
  `-vsync passthrough`；ffmpeg 7（已删除 `-vsync`）也不受影响。无需再用手动 wrapper 绕行。
  The encoder hardcoded `-fps_mode vfr` (ffmpeg ≥ 5.1); on ffmpeg 4.4 the process exited instantly and the
  viewer never showed video. The argument form is now probed once per process and falls back to
  `-vsync passthrough` on old ffmpeg; ffmpeg 7 (which removed `-vsync`) is unaffected.
