修复 X11 桌面首次扫码登录偶发崩溃（段错误）。/ Fix a sporadic segfault on first QR login on X11 desktops.

### 修复 / Fixed
- **`uuremote-server login` 在 X11 桌面首次运行可能崩溃**：GTK 登录窗口线程先打开了 X 连接，而
  `XInitThreads()` 直到设备注册探测屏幕时才被调用（太晚，返回 0），libX11 全程未启用锁，GTK 线程与后台
  线程并发调用 Xlib 导致段错误（`XrmQGetResource → pthread_mutex_lock(NULL)`）。已在设备上复现 3/3。
  现在 `XInitThreads()` 在 C 库构造函数中执行（先于 `main()`），从机制上保证不会再有此类时序问题。
  已注册过设备（config.json 已有 device_id）的机器不会触发该路径，所以老用户无感。
  First-run `login` segfault on X11: GTK opened its X connection before `XInitThreads()` ran, leaving
  libX11 unlocked while two threads used it concurrently. `XInitThreads()` now runs in a C library
  constructor before `main()`. Machines that already registered only avoided the code path by luck.
