# v0.1.15

## 修复

- **关掉一个显示器后鼠标漂移（KDE Wayland / portal + uinput）**：绝对坐标映射只在抓屏初始化时
  解析一次，而 `ScreenCapture` 和它的 portal 会话会跨连接复用；禁用/启用显示器改变输出布局后，
  旧映射继续把 uinput 全桌面坐标按旧包围盒换算，落点整体偏移。现在每次桌面连接都重新枚举
  xdg-output 布局并重算映射（`ScreenCapture::fresh_absolute_mapping`，`src/main.rs` 的 offer
  处理处）。同时 portal 会话建立时缓存的流 `position` 若与当前任何输出的起点都对不上（例如
  被抓的屏幕在布局变化后移动了），视为过期坐标，回退到按逻辑尺寸唯一匹配输出。

## 验证

- `cargo test --locked`：122 passed（新增过期 position 回退用例）。
- `cargo check --features wayland,portal` 通过。
- v0.1.14 的 CI deb 已在 ubuntu:22.04 容器内端到端验证（安装 + Xvfb + `desktop-video-probe`，
  ffmpeg 4.4 自动回退 `-vsync passthrough`，正常编码出帧）。
