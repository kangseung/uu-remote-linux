# v0.1.19

## 修复

- **「被控端版本较低」永久性修复**：`x-param-vn` 不再依赖编译期常量。新增
  `src/client_version.rs`，启动时和每 6 小时在后台读取官方 Windows 版版本号：
  - 官方下载页 JSON-LD 的 Windows `softwareVersion`（`major.minor.patch`）；
  - winget 仓库 `NetEase/UURemote` 的清单目录（完整 `major.minor.patch.build`）；
  - 取两者中较新的一个上报；取不到时沿用内置基线 `4.48.4.6020`，失败 1 小时后重试。
  检测值只会向前抬升，不会回退；日志只打印版本号，不含任何凭据。

## 安装体验

- **deb 安装/升级后自动生效**：`postinst` 通过 logind 找到已登录用户，为其
  `systemctl --user daemon-reload` 并 `try-restart`（升级）或 `start`（首次安装）
  `uuremote-server.service`，不再需要手动执行 `systemctl --user enable --now`。
  没有运行 user manager 的用户跳过，仍由 `--global enable` 在下次登录时启动。
- README 中删除手动启动服务的步骤，并说明版本号自动跟随官方。

## 注意

`UU_CLIENT_VERSION` 仍是最高优先级覆盖，显式设置后自动检测不会覆盖它，可用于临时回退：
`UU_CLIENT_VERSION=4.45.0.4318 uuremote-server`。

## 验证

- `cargo test`：`client_version` 解析（只取 Windows 条目、取最高 winget 版本、不回退）
  与既有的版本上报断言全部通过。
- `packaging/deb/build-deb.sh` 构建 0.1.19 deb；安装后日志出现
  `Reported client version ...` 且服务自动重启。
