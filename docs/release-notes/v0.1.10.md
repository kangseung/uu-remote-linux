手机输入法直输文字（含中文）、多显示器下单屏抓取的鼠标偏移修复、锁屏画面可选推流。/ Phone IME typing (incl. CJK), pointer-offset fix for single-screen capture on multi-monitor setups, opt-in lock-screen streaming.

### 新增 / Added
- **手机系统输入法直接打字**：控制端输入法的 `text_input` 消息现在会被处理。ASCII 字符按真实按键注入；
  中文等非 ASCII 通过剪贴板瞬时粘贴（保存并恢复原剪贴板内容）。终端窗口里粘贴快捷键是 Ctrl+Shift+V，
  该场景下非 ASCII 粘贴无效，为已知限制。
  Phone IME text now reaches the desktop: ASCII as keystrokes, non-ASCII via a clipboard paste that
  saves and restores the previous selection. Known limitation: paste does not reach terminal windows.
- **`UU_STREAM_LOCK_SCREEN=1`**：锁屏时继续推流并允许输入（KDE 锁屏画面可被抓取，可在锁屏界面直接输密码）；
  默认仍为锁屏置黑以保护隐私。/ Opt-in lock-screen streaming (works on KDE); default stays blank for privacy.

### 修复 / Fixed
- **多显示器只抓单屏时鼠标指针偏移**：uinput 绝对坐标被合成器映射到整个桌面范围，单屏抓取时点击落点错位。
  现在通过 xdg-output 枚举显示器布局并按 portal 流的位置换算坐标；无法获取布局时保持原行为。
  Pointer offset when capturing one of several monitors via ScreenCast+uinput: coordinates are now
  transformed through the output layout (xdg-output) and the portal stream position.
