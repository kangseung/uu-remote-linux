KDE/GNOME Wayland 下可以用 uinput 输入 + ScreenCast 会话抓屏，授权时可选单块屏幕；新增 deb 安装包，装完自动开机自启。/ On KDE/GNOME Wayland, uinput input plus a ScreenCast capture session allows per-screen selection at consent time; new deb package with autostart.

### 新增 / Added
- **Debian/Ubuntu deb 安装包**：`sudo apt install ./uuremote-server_*_amd64.deb` 一条命令装好——自动声明运行时依赖，
  内置 udev uaccess 规则（uinput 输入所需）和 systemd 用户服务（登录自启、崩溃 5 秒自拉起）。
  装好后只需在桌面里运行一次 `uuremote-server login` 扫码，之后永久自动上线。
  One-command deb install: runtime dependencies, the uinput udev rule and an auto-restarting user service are all included;
  scan the QR once with `uuremote-server login`, then the host stays online.

### 改进 / Improved
- **KDE/GNOME Wayland 可选单块屏幕**：输入走 `/dev/uinput` 时，抓屏改用纯 ScreenCast portal 会话。
  KDE Plasma 6.3 的 RemoteDesktop 授权框没有屏幕选择、默认合并整个工作区；ScreenCast 对话框可以逐屏选择，
  授权可记住，剪贴板改走 wl-clipboard。uinput 不可用（未配 udev 规则或 `UU_INPUT_BACKEND=native`）时行为与旧版完全一致。
  With uinput input, capture uses a pure ScreenCast portal session whose dialog offers per-screen selection
  (the Plasma 6.3 RemoteDesktop dialog does not); clipboard falls back to wl-clipboard. Without uinput nothing changes.
- 发布的 tarball 也带 `wayland,portal` 特性，与 deb 一致。/ Release tarballs now ship the same wayland,portal build.
