# v0.1.18

## 修复

- **官方控制端再次提示「被控端版本较低」**：v0.1.17 上报的 `4.45.0.4318` 已被官方 Windows 客户端
  超越（当前 `4.48.4.6020`），控制端又把被控端判为落后。`DEFAULT_CLIENT_VERSION` 提升到
  `4.48.4.6020`：
  - `x-param-vn` → `4.48.4.6020`，`x-param-vc` → `6020`；
  - `User-Agent` → `UURemote/4.48.4 (Windows NT 10.0; Win64; x64)`。

  版本号仍只在 `src/auth.rs` 的 `DEFAULT_CLIENT_VERSION` 维护；官方再升版时也可以不重新编译，
  用 `UU_CLIENT_VERSION=4.50.0.5000 uuremote-server` 临时覆盖。

## 注意

控制端会按被控端上报的版本决定发送哪些新协议消息。若新特性表现异常，可用
`UU_CLIENT_VERSION=4.45.0.4318` 退回上一版声明，并对照
`CONTROL message: fields=[..]` 日志排查。

## 验证

- `cargo test`：`auth::reported_version_tests` 断言默认版本、版本号（`6020`）与
  `UURemote/4.48.4` User-Agent。
